Task 29 の修正で楽天 1,000 件の抽出が完走した（失敗バッチ 0）。抽出品質自体は良く、
ジムビーム・グレンファークラス・グレンアラヒー・オールドパー・イチローズモルト・軽井沢・
キルホーマン等、実在の銘柄が正しく取れている。幻覚は見当たらない。

### 欠陥 1: 日本語の冠詞「ザ・」が正規化されていない

```
brands.json に存在:  macallan  → brand_ja='マッカラン'  aliases=['THE MACALLAN','マッカラン','The Macallan']
提案に出てしまう:    ザ・マッカラン   6件
                    ザ グレンリベット 4件（glenlivet も既知）
```

`comparison_keys`（`scripts/extract_whiskey_names_claude_sonnet.py:95-101`）は
英語の `the ` 接頭辞のみ除去しており、**日本語の `ザ・` / `ザ ` / `ザ` は対象外**。
既知ブランドが未知として提案されている。

### 欠陥 2: 同一ブランドが複数の提案キーに分裂する

```
proposed_0af5a2edd4  ['ジムビーム']                      12件
jim_beam             ['ジムビーム','Jim Beam','ジム ビーム']  5件   ← 同一ブランド
proposed_69c4920971  ['グレンファークラス']                12件
glenfarclas          ['グレンファークラス','Glenfarclas']    3件   ← 同一ブランド
proposed_c4e2758095  ['アマハガン']                       4件
amahagan             ['AMAHAGAN','アマハガン']              4件   ← 同一ブランド
```

原因は `proposed_brand_key`（同 104-115）が **`brand_en` からスラッグを作り、
`brand_en` が無い場合だけ日本語ラベルのハッシュにフォールバック**すること。
同じブランドでも、そのタイトルでモデルが `brand_en` を返したかどうかでキーが変わる。

## 実装内容

### 1. 日本語の冠詞を正規化する

`comparison_keys` に日本語の冠詞パターンを追加する:

- `ザ・` / `ザ ` / `ザ`（先頭のみ）
- `THE ` / `The ` / `the `（既存）

既知ブランドとの突き合わせで `ザ・マッカラン` → `マッカラン` が一致すること。

**注意:** 冠詞除去は**先頭に限る**こと。ブランド名の途中の「ザ」を削ってはならない
（例: `ニッカ ザ ネッサンス` のような名前で誤動作させない）。
また 1〜2 文字しか残らなくなる場合は除去しないこと。

### 2. 提案キーを表記に依存させない

同一ブランドが複数キーに分裂しないようにする。方針:

- **観測された表記（日本語・英語の両方）を突き合わせて、同一ブランドを 1 つの提案に束ねる**
- 束ねる判定は正規化後の完全一致（`normalize_label` + 冠詞除去）で行う。
  **fuzzy による自動統合はしないこと**（`Arran/Aran` = 0.889 の反例があり、
  別ブランドを誤って統合する危険がある）
- 日本語表記だけで観測されたブランドと、後から英語表記付きで観測された同じブランドが
  **1 つの提案に統合される**こと
- `brand_key` は安定して決まること（処理順序に依存しない）。
  英語表記が観測されていればそれを優先し、無ければ日本語からの決定論的なキーにする

### 3. 提案の中身を充実させる

人手レビューを現実的にするため、各提案に以下を含める:

- `observed_variants`: 観測された全表記（日本語・英語）
- `occurrence_count`: 統合後の合計出現件数
- `sample_source_titles`: 代表 3 件（既存）
- **`suggested_aliases`: 観測された表記のみからなる候補一覧**
  （**モデルに生成させたものを含めないこと**。あくまで実際にタイトルに現れた文字列）

出現件数の降順で並べること。

### 4. 既知ブランドとの突き合わせを強化

`ザ・` 正規化を入れた上で、既知ブランドに一致するものは提案に出さないこと。
サマリで「既知ブランド一致件数」が増え、「未知ブランド件数」が減ることを確認できるようにする。

## テスト（Bedrock を呼ばないこと。応答はスタブ）

1. **`ザ・マッカラン` が既知ブランド `macallan` に一致し、提案に出ない**

9. 提案が `occurrence_count` の降順で並ぶ
