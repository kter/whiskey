# Task 31: 蒸留所名での読み取りをブランドに解決できるようにする

## 背景（dev の実データで再現）

ブランド軸を dev に反映して実写真で確認したところ、照合できない実例が出た。

```
brand_ja: "遊佐蒸溜所"        → brand_key: null   （カタログには yuza があるのに外れる）
brand_en: "The Yuza Distillery"
```

原因は2つ。

1. `_load_brand_catalog`（`lambda/drink-log-analyze/index.py:79`）が照合名を
   **`brand_ja` / `brand_en` / `aliases` からしか作っていない**。`distillery_ja` /
   `distillery_en` が候補に入っていない。
2. ラベルには「遊佐蒸溜所」「The Yuza Distillery」のように**蒸留所の接尾辞付き**で
   書かれていることがある。621の指摘②「ラベルに書いてある一番大きい文字が
   ウイスキーの名前ではなく蒸留所名の場合もある」がこれに当たる。

別名を1ブランドずつ足して回るのは、**今後追加するブランドで同じ穴が再発する**。
接尾辞を正規化して解く。

## スコープ

`lambda/drink-log-analyze/index.py` と `tests/lambda/test_drink_log_analyze.py` のみ。
**カタログのデータ（`brands.json` 2ファイル）は変更しない。**
`infra/` `lambda/drink-logs/` `frontend/` `scripts/` も変更しない。

---

## 変更1: 照合名に蒸留所名を含める

`_load_brand_catalog` が組み立てる `names` に **`distillery_ja` と `distillery_en`** を加える。
空文字の場合は従来どおり無視すること（`macrie_moor` を消した今も、
蒸留所欄が空のブランドは将来また現れる）。

## 変更2: 蒸留所の接尾辞を落とした変種も登録する

各名前について、**接尾辞・接頭辞を落とした変種**を照合名に追加する。

- 日本語の接尾辞: `蒸溜所` / `蒸留所` / `蒸溜` / `蒸留`（末尾のみ）
- 英語の接尾辞: `Distillery` / `Distillers`（末尾のみ、大文字小文字を問わない）
- 英語の接頭辞: `The `（先頭のみ、大文字小文字を問わない）

例: `遊佐蒸溜所` → `遊佐` も登録。`The Yuza Distillery` → `Yuza` も登録。

**同じ正規化を、モデルが返した `brand_ja` / `brand_en` 側にも適用すること。**
ラベル側が接尾辞付き・カタログ側が無しでも、逆でも当たるようにする。
正規化は既存の `whiskey_common.normalize.normalize_text` を土台に使い、
**第2の正規化系を作らないこと**。接尾辞処理は薄いヘルパーとして足す。

変種を作った結果が空文字になる場合は登録しない
（例: 名前が `蒸溜所` だけ、といった異常データ）。

## 変更3: 衝突が起きていないことを保証する

`_brand_catalog_match` は候補が2件以上に一致した場合 `None` を返す
（任意のキーを付けない安全側の設計）。変種を増やすと**これまで当たっていたブランドが
衝突して当たらなくなる**危険がある。

**受入条件として、実カタログ60件に対して正規化後の照合名に重複が無いことを
テストで検証すること。** 重複があればテストが落ちるようにし、
どのブランドが衝突したか分かるメッセージを出す。

---

## テスト（`tests/lambda/test_drink_log_analyze.py`）

- **`brand_ja: "遊佐蒸溜所"` が `yuza` に解決される**こと（本タスクの回帰テスト）
- **`brand_en: "The Yuza Distillery"` が `yuza` に解決される**こと
- カタログ側が接尾辞付き（`distillery_ja: "厚岸蒸溜所"`）でモデルが `"厚岸"` と
  返した場合も解決されること
- 「蒸留所」「蒸溜所」の表記差を吸収できること
- **実カタログ60件で正規化後の照合名に衝突が無い**こと
- 既存テストが緑のまま（特に曖昧なブランド名で任意のキーを付けない分岐）

## 受入条件

- `python -m pytest tests` が全通過
- `git diff --stat -- infra/ lambda/drink-logs/ frontend/ scripts/` が**空**
- `brands.json`（2ファイルとも）が**無変更**、かつ相互にバイト一致のまま
- 正規化系を2つに増やしていないこと
- 依存追加なし
